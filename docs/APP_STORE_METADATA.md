# App Store / TestFlight Metadata Draft

This file is a draft for App Store Connect. It describes only features implemented in the repository.

## English

Name: CapturePilot

Beta Description:
CapturePilot is a free, ad-free iPhone camera with professional manual controls and an on-device photography coach. The current beta includes HEIF/JPEG capture, RAW when supported by the active device configuration, lens switching, tap-to-focus, manual exposure/focus/white balance, composition guides, horizon/person/saliency analysis, and English/Spanish/System language controls.

What to Test:
Please test full-screen camera layout, lens switching, HEIF/JPEG/RAW availability, tap-to-focus, manual exposure/focus/white balance, coach stability, photo saving, and language switching. Report your iPhone model and iOS version with any issue.

Privacy Summary:
No account, ads, third-party analytics, or CapturePilot cloud upload exists in the current build. Live coach analysis is performed on-device.

## Español

Nombre: CapturePilot

Descripción beta:
CapturePilot es una cámara gratuita y sin anuncios para iPhone con controles manuales profesionales y un coach fotográfico en el dispositivo. La beta actual incluye captura HEIF/JPEG, RAW cuando la configuración activa del dispositivo lo soporta, cambio de lente, tocar para enfocar, exposición/enfoque/balance de blancos manual, guías de composición, análisis de horizonte/persona/saliencia y selector Inglés/Español/Sistema.

Qué probar:
Prueba el visor a pantalla completa, cambio de lentes, disponibilidad HEIF/JPEG/RAW, tap-to-focus, exposición/enfoque/balance de blancos manual, estabilidad del coach, guardado y cambio de idioma. Incluye modelo de iPhone y versión de iOS al reportar problemas.

Resumen de privacidad:
La compilación actual no tiene cuenta, anuncios, analítica de terceros ni subida a una nube de CapturePilot. El análisis del coach se realiza en el dispositivo.
