# Roadmap / Hoja de ruta

This roadmap is ordered by dependency and testability, not marketing priority.

## 0.1 — Camera + coach baseline

- [x] AVFoundation preview and capture
- [x] HEIF/JPEG
- [x] RAW when supported
- [x] Lens switching
- [x] EV / ISO / shutter / focus / white balance
- [x] Tap-to-focus and tap-to-meter
- [x] Horizon / person / saliency / luminance coach
- [x] Thirds / golden-ratio / crosshair guides
- [x] English / Spanish / System
- [x] Privacy Manifest

## 0.2 — Exposure and focus tools

- [ ] Real-time luminance histogram
- [ ] Zebra overlay with adjustable clipping threshold
- [ ] Focus peaking using an edge/high-frequency pipeline
- [ ] Improved capture/readiness feedback
- [ ] Better device capability reporting

## 0.3 — Composition intelligence

- [ ] Leading-line detection
- [ ] Symmetry analysis
- [ ] Vanishing-point estimation
- [ ] Negative-space analysis
- [ ] Golden triangle and spiral overlays
- [ ] Better multi-subject grouping

## 0.4 — Scene coaches

- [ ] Portrait
- [ ] Architecture
- [ ] Automotive
- [ ] Macro
- [ ] Street
- [ ] Landscape
- [ ] Night

Each scene mode must change real analysis rules before it becomes visible in the app.

## 0.5 — Professional capture

- [ ] Apple ProRAW where supported
- [ ] Bracketing workflows
- [ ] Capture stabilization/readiness assistance
- [ ] Metadata review
- [ ] Optional post-capture teaching review

## Principle / Principio

A roadmap item is not marked complete until it can be demonstrated on a physical device. / Una función no se marca como terminada hasta poder demostrarla en un dispositivo físico.
